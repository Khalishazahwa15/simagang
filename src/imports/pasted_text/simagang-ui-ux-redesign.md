Design a complete high-fidelity UI/UX redesign for a government internship management web application called:

“SIMAGANG”
Sistem Informasi Pengelolaan Magang Mahasiswa
BAPPEDA PROVINSI LAMPUNG

IMPORTANT:
This is a real government/public-service digital product, not a startup landing page, SaaS dashboard, fintech product, or generic AI-generated website.

The design must feel:
- official
- trustworthy
- institutional
- human
- contemporary
- sophisticated
- calm
- accessible
- professional
- highly usable

But DO NOT make it:
- overly minimalist
- generic
- sterile
- overly corporate
- visually empty
- template-like
- “AI generated”
- similar to common SaaS dashboards
- full of excessive rounded cards
- full of gradients
- full of floating glassmorphism
- overly decorative

The goal is a distinctive government digital service identity that feels carefully art-directed by a professional UI/UX designer.

==================================================
1. DESIGN DIRECTION
==================================================

Create a visual language inspired by modern Indonesian public institutions, editorial government publications, civic technology, and contemporary information systems.

The interface should communicate:
1. Trust
2. Public service
3. Government authority
4. Transparency
5. Accessibility
6. Administrative precision
7. Digital modernization

The visual style should combine:
- institutional design
- editorial typography
- structured layouts
- subtle local visual character
- restrained modernism
- strong information hierarchy

Avoid the typical “AI website” appearance where every section consists of:
icon + rounded white card + shadow + centered heading.

Instead, use a richer visual hierarchy:
- asymmetric but balanced layouts
- editorial section compositions
- large typography
- strong section dividers
- intentional whitespace
- subtle borders
- structured grids
- numbered process elements
- timeline patterns
- document-inspired components
- data visualization
- institutional labels
- restrained decorative motifs

Use visual hierarchy rather than excessive decoration.

==================================================
3. TYPOGRAPHY
==================================================

Create a distinctive typographic hierarchy.

Use a refined serif display font for major editorial headlines.

Suggested:
DM Serif Display / Playfair Display / Libre Baskerville
Choose ONE.

Use a clean modern sans-serif for UI, body text, labels, navigation, forms, and tables.

Suggested:
Inter / Manrope / Plus Jakarta Sans
Choose ONE.

Typography should create a strong contrast:
EDITORIAL SERIF = institutional storytelling / major headlines
SANS-SERIF = functionality / data / administration

Do not use too many fonts.

Use:
- large editorial headings
- compact uppercase eyebrow labels
- readable body text
- clear metadata
- strong numerical typography

Headings should feel sophisticated and editorial, not like a generic SaaS template.
